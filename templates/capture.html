📥 Packet Capture

Live packet sniffing needs raw-socket access (root/administrator) and a blocking capture loop, so it isn't triggered from a web request. Run it separately from a terminal with elevated privileges:

sudo python3 capture/packet_capture.py

This appends captured packets to data/traffic.csv, which the Ports, Risk, and AI Detector pages read from automatically. Requires scapy and a supported interface/driver (libpcap on Linux/macOS, Npcap on Windows).
