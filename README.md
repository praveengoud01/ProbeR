# ProbeR - AI Powered Network Threat Detection System

## Overview

ProbeR is a cybersecurity monitoring platform developed using Python, Flask, SQLite, and Machine Learning concepts.

The system captures and analyzes network traffic, detects suspicious activities, stores threats in a database, generates reports, and provides a web dashboard for monitoring.

## Features

* Network Traffic Analysis
* Port Activity Detection
* Risk Scoring Engine
* AI Threat Detection
* Threat Database Storage
* Live Monitoring
* Web Dashboard
* Login Authentication
* Threat Analytics Charts
* CSV Report Export

## Technologies Used
